# Rules for agents working on ForgeCLI

Before proposing or making any change to ForgeCLI, answer: **what does it
change in real use**, for someone running ForgeCLI on their own project, at
the terminal or in a script, not only on a benchmark? Put that answer in the
proposal. A change whose only effect is a benchmark score is not proposed.
